# Music licences

Every song needs a licence file in this folder before it ships, including generated placeholder audio.
One Markdown file per song, named after the song id (for example `neon-nights.md`).

Each file records:

- Title, and the song id used in the app
- Composer and rights holder
- Source: commissioned, library, own work, or generated (name the tool and its terms)
- Licence type, with the full text or a link to it
- What it permits: commercial use, use inside an app or game, distribution through the App Store,
  modification and separate stems
- Required attribution wording, if any
- Territory and term
- Proof: the agreement, invoice or order reference, and its date

Not allowed: popular songs without a licence, and anything taken from other rhythm games, including
community charts of commercial songs.
